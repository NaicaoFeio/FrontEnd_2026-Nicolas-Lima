Usando new ()

Usando Static

funciona como int main, static permite que o 'main' seja o ponto de partida, executado antes de qualquer criação

Diferença Double e Float

Float: ocupa 32 bits na memoria, aguenta ate 7 casas decimais, usado mais quando tem muitos numeros quebrados e precisar economizar RAM Double: ocupa 64 bits, aguenta ate 15 casa decimais, mais usado em calculos cientificos

Perda de Ref

depois que usamos o metodo, a variavel fica inacessivel e perdida na heap, sendo coletada pelo garbage collector

Stack e Heap

Stack:armazena os endereços(referencias) que apontam para o heap Heap:armazena a instacia(dados) que serao apontados pelo stack
